# GOAT Agent — установщики

[Выпуски и файлы для скачивания](https://github.com/hello1e3/goat-agent-releases/releases)

Windows-приложение с интерфейсом WPF, коричневым Acrylic и собственным AI-провайдером. Для работы нужны API Base URL, ключ и точное имя модели с поддержкой инструментов. Подписки ChatGPT/Claude не заменяют API-ключ.

## Статус preview 0.2.0

- Windows 10 22H2 / Windows 11 x64, .NET Framework 4.8. Node и WebView2 включены в установщик.
- Установщик без сертификата издателя; возможны предупреждения Windows. Защиту отключать не следует.
- Публичный сервер лицензирования ещё не развёрнут. На новом компьютере без настроенного сервера и кода пройти активацию нельзя. Это тестовый выпуск, пока не готовый к продаже.
- Проверки действий выполнялись с локальным тестовым API; платный API конкретной компании не проверялся.
- Mac Intel/Apple Silicon установщиков пока нет.

Исходники хранятся отдельно в приватном репозитории владельца. Здесь публикуются только установщики и информация о выпусках.
